# Actions

Clase base de todos los recursos: ofrece `read`, `list`, `create`, `update`, `delete` y `add_attachment`. También incluye `validate_id`, la función que valida los IDs antes de construir la URL (ver [Seguridad](../guias/seguridad.md#validacion-de-ids)).
